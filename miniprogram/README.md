# 小笺微信小程序

这是小笺的原生微信小程序版本，功能和桌面/PWA 版本保持一致的数据格式，但界面使用 WXML、WXSS 与小程序 API 单独实现。

## 当前功能

- 按日期新增、完成、编辑和删除待办
- 原生日历选择、前后日期切换
- 前一天未完成事项续到当天
- 历史记录与关键词搜索
- 微信本地存储，关闭后仍可继续使用
- 基于微信 OpenID 的 CloudBase 多设备自动同步
- JSON 文件或剪贴板备份导出、导入并合并

## 在微信开发者工具中运行

1. 安装微信开发者工具。
2. 选择“导入项目”，目录选择本仓库根目录。
3. `project.config.json` 已配置小程序 AppID `wxa3b2d716724f4f64`。
4. 使用已被添加为该小程序管理员或项目成员的微信账号扫码登录。
5. 打开“云开发”，确认环境 `xiaojian-note-d6g8woyu3eddba850` 可用。
6. 在云数据库中新建集合 `daily_note_users`，权限选择“仅创建者可读写”。
7. 点击“编译”预览；确认功能后点击“上传”，再到微信公众平台提交审核。

AppID 是公开标识，可以提交到仓库；不要把 AppSecret、上传私钥或微信密码提交到仓库。

## 数据说明

小程序采用“本地优先 + 云端自动合并”：每次操作先写入当前设备，断网时仍可使用；进入小程序、恢复到前台、网络重连或本地数据变化后，会自动通过 CloudBase 合并到云端，不再需要同步开关或手动点击。同一个微信账号在不同设备中会使用相同的小程序 OpenID，不需要额外注册账号。

云端不会读取真实微信号、昵称或手机号。集合必须保持“仅创建者可读写”，避免不同用户之间访问数据。删除操作使用墓碑记录参与合并，防止旧设备把已经删除的待办恢复回来。

手动 JSON 导出/导入仍然保留，可用于桌面版、网页版互通和额外备份。环境 ID 与 AppID 都是公开标识；不要提交 AppSecret、上传私钥或腾讯云密钥。
