# 小笺微信小程序

这是小笺的原生微信小程序版本，功能和桌面/PWA 版本保持一致的数据格式，但界面使用 WXML、WXSS 与小程序 API 单独实现。

## 当前功能

- 按日期新增、完成、编辑和删除待办
- 原生日历选择、前后日期切换
- 前一天未完成事项续到当天
- 历史记录与关键词搜索
- 微信本地存储，关闭后仍可继续使用
- JSON 文件或剪贴板备份导出、导入并合并

## 在微信开发者工具中运行

1. 安装微信开发者工具。
2. 选择“导入项目”，目录选择本仓库根目录。
3. 当前 `project.config.json` 使用 `touristappid`，可用于本地预览部分能力。
4. 准备发布时，把 `project.config.json` 的 `appid` 改成你在微信公众平台获得的小程序 AppID。
5. 使用小程序管理员微信扫码登录开发者工具，点击“上传”，再到微信公众平台提交审核。

只需要提供 AppID，不要把 AppSecret、上传私钥或微信密码提交到仓库。

## 数据说明

当前版本不连接服务器，也没有开启云开发。数据保存在当前设备的微信小程序存储中；换手机不会自动同步。可以在“设置”中导出 JSON，再在另一台设备、桌面版或网页版中导入并合并。

如果以后需要自动同步，可以在不改变页面业务逻辑的情况下，把 `utils/store.js` 扩展为“本地存储 + 云端增量同步”。
